# ex02_digit_print — 递归正序与逆序输出数字

## 作业内容

读入一个整数 `n`，分别用递归按正序和逆序输出它的每一位数字，数字之间以空格分隔：先输出正序一行，再输出逆序一行。

## 涉及知识点

- `scanf("%d", &n)` 读入整数
- 递归函数：正序先 `forward(n/10)` 再打印 `n%10`，逆序先打印 `n%10` 再 `back(n/10)`
- 递归终止条件 `n == 0` 直接返回
- `n % 10` 取末位、`n / 10` 去掉末位
- 用 `n >= 10` / `n / 10 != 0` 判断是否还需要输出空格
