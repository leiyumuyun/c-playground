# ex03_hanoi — 汉诺塔步数

## 作业内容

读入盘子数 `n`，用递归计算把 `n` 个盘子从 A 柱经 B 柱移到 C 柱所需的最少移动步数并输出。

## 涉及知识点

- `scanf("%d", &n)` 读入盘子数
- 递归分解：先把 `n-1` 个盘子从 `from` 经 `to` 移到 `via`，再移动最大盘，最后把 `n-1` 个盘子从 `via` 经 `from` 移到 `to`
- 递归终止条件 `n == 1` 返回 1
- 用 `long long` 累加步数避免溢出，用 `%lld` 输出
- 字符参数表示三根柱子 `'A'`、`'B'`、`'C'`
