# Week 09 — 递归与随机数

上课日期：2026-11-05

本周共 3 个作业，每个作业一个子目录，源码统一叫 `main.c`，编译运行方法见各子目录的 `README.md`。

## 作业列表

| 目录 | 作业 | 内容 |
|---|---|---|
| [ex01_guess_number/](ex01_guess_number/) | 猜数大小提示 | 用 `srand(s)` 和 `rand()%100+1` 生成目标数，读入猜测值，互斥判断后输出“猜得太大”“猜得太小”或“猜对了”。 |
| [ex02_digit_print/](ex02_digit_print/) | 递归正序逆序输出数字 | 用两个递归函数，分别先递归后打印、先打印后递归，按正序和逆序输出整数的各位数字。 |
| [ex03_hanoi/](ex03_hanoi/) | 汉诺塔步数 | 递归把 n 个盘子分治为 n-1 个盘子的两次移动加一次最大盘移动，用 `long long` 累加并输出最少步数。 |

## 本周知识点

- `srand` / `rand` 伪随机数生成与取模限定范围
- `if` / `else if` / `else` 互斥分支
- 递归函数的设计：终止条件 + 递归调用 + 本层操作
- 正序与逆序递归的打印顺序差异
- 分治思想（汉诺塔）
- `long long` 与 `%lld` 处理大整数
