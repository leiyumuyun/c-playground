# ex02_print_primes — 输出素数

## 作业内容

读入正整数 `n`，输出 2 到 `n`（含 `n`）之间的所有素数，每个数后跟一个空格。对每个 `i` 调用 `num`：`i == 2` 直接输出；否则用 `t` 从 2 试到 `t * t <= i`，一旦 `i % t == 0` 就判定不是素数并 `return`，试完没有因子才输出。

## 涉及知识点

- `scanf("%d", &n)` 读入整数，`for` 循环枚举 2 到 n
- 素数判定只需试除到 √i，条件是 `t * t <= i`
- 用 `return` 提前结束函数，跳过输出
- 单独处理 `i == 2`：`else` 分支的循环从 2 开始，会把 2 误判为合数
- `printf("%d ", i)` 输出，数字之间用空格分隔

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
