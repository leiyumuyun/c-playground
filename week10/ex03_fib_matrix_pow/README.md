# ex03_fib_matrix_pow — 斐波那契取模（矩阵快速幂）

## 作业内容

读入 `n`，输出斐波那契数列第 `n` 项对 9999 取模的结果。把递推写成矩阵形式：底矩阵 `[[1,1],[1,0]]` 的 `n` 次幂等于 `[[F(n+1), F(n)], [F(n), F(n-1)]]`。用二进制快速幂累乘 2×2 矩阵，结果矩阵的右上角就是 `F(n)`。

## 涉及知识点

- `scanf("%lld", &n)` 读入 `long long`，`printf("%lld\n", ...)` 输出
- 2×2 矩阵乘法，利用对称性只存 `x, y, z` 三个元素（矩阵形如 `[[x,y],[y,z]]`）
- 二进制快速幂：`n & 1` 判断当前二进制位，`n >>= 1` 右移
- 单位矩阵 `[[1,0],[0,1]]` 作累乘初值，底矩阵取 `[[1,1],[1,0]]`
- 每次乘法后 `% MOD` 防溢出，`MOD` 用 `#define` 定义为 9999

gcc main.c -o main -Wall -Wextra
./main
