# ex01_perfect_number — 完数

## 作业内容

读入正整数 `n`，输出小于 `n` 的所有完数。完数指等于自身所有真因子之和的数，例如 6 = 1 + 2 + 3。对每个候选数 `i`，因子和 `sum` 从 1 开始，用 `q` 从 2 试到满足 `q * q < i`，能整除时把 `q` 和 `i / q` 成对累加；最后 `sum == i` 就输出 `i`。

## 涉及知识点

- `scanf("%d", &n)` 读入整数，`for` 循环枚举候选数
- 自定义函数 `void num(int i)` 封装单个数的判定
- 试除法找因子：`i % q == 0`，成对累加 `q` 和 `i / q`
- 因子和从 1 开始（1 是真因子），循环从 2 开始
- `if (sum == i)` 判断完数并输出

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
