# ex04_trim_spaces — 压缩连续空格

## 作业内容

用双指针原地压缩：`r` 往后读、`w` 往后写，连续空格只保留一个，读完在 `w` 处补 `'\0'` 并输出。

## 涉及知识点

- 双指针原地覆盖写，不额外开数组
- `fgets` 读整行，压缩时跳过 `'\n'`
- 标志位记录上一个写出的字符是不是空格
- `w` 永远不超过 `r`，所以原地写不会越界
- 末尾补 `str[w]='\0'` 才能当字符串输出

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
