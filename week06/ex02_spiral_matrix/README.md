# ex02_spiral_matrix — 螺旋矩阵

## 作业内容

读入 n，用二维数组按右→下→左→上的顺序填入 1 到 n²：每走一步先看前面是否越界或已填，不能走就转向；最后按 `%4d` 对齐输出。

## 涉及知识点

- `memset(a, 0, sizeof a)` 清零二维数组
- `turn` 变量做四方向状态机
- 「前方可走」判断：下标不越界且 `a[..]==0`
- 二维变长数组 `int a[n][n]`
- `%4d` 对齐输出，行末换行

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
