# Week 06 — 字符串与二维数组

上课日期：2026-10-22

本周共 4 个作业，每个作业一个子目录，源码统一叫 `main.c`，编译运行方法见各子目录的 `README.md`。

## 作业列表

| 目录 | 作业 | 内容 |
|---|---|---|
| [ex01_title_case/](ex01_title_case/) | 单词首字母大写 | 用 `fgets` 读一整行并去掉行尾换行，遍历时遇到空格就置标志位，让每个单词的首字母变大写、其余字母变小写。 |
| [ex02_spiral_matrix/](ex02_spiral_matrix/) | 螺旋矩阵 | 读入 n，用二维数组按右→下→左→上的顺序填入 1 到 n²：每走一步先看前面是否越界或已填，不能走就转向；最后按 `%4d` 对齐输出。 |
| [ex03_next_permutation/](ex03_next_permutation/) | 下一个字典序排列 | 从后往前找第一个 `a[i] < a[i+1]` 的拐点，再从后往前找第一个大于 `a[i]` 的元素交换，最后把 `i` 之后的降序后缀反转成升序，得到下一个排列；找不到拐点说明已是最大排列，原样输出。 |
| [ex04_trim_spaces/](ex04_trim_spaces/) | 压缩连续空格 | 用双指针原地压缩：`r` 往后读、`w` 往后写，连续空格只保留一个，读完在 `w` 处补 `'\0'` 并输出。 |

## 本周知识点

- `fgets` 读整行并手动去掉 `\n`
- 标志位记录「是否在单词开头」
- 双指针原地压缩字符串
- `memset` 清零与二维 VLA `int a[n][n]`
- 四方向状态机（螺旋矩阵）
- 双指针 + 区间反转（下一个排列）
