# ex03_next_permutation — 下一个字典序排列

## 作业内容

从后往前找第一个 `a[i] < a[i+1]` 的拐点，再从后往前找第一个大于 `a[i]` 的元素交换，最后把 `i` 之后的降序后缀反转成升序，得到下一个排列；找不到拐点说明已是最大排列，原样输出。

## 涉及知识点

- 双指针从后往前扫描找拐点
- 交换与「反转降序后缀」两步得到下一个排列
- 逗号表达式一次写三个赋值：`tmp=a[i],a[i]=a[s],a[s]=tmp`
- 降序后缀的性质：反转即得最小排列
- `main` 没有写 `return 0`

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
