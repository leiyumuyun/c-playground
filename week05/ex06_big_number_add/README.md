# ex06_big_number_add — 大数加法

## 作业内容

读入两个长度不超过 500 位的十进制数，倒序逐位存进整型数组，数组逐位相加并处理进位，最后再倒序输出结果。

## 涉及知识点

- 字符串倒序转数组：`a[i]=str[len-1-i]-'0'`
- `char` 减 `'0'` 得到数值
- 数组初始化为 0，空位自动补 0
- 进位：`c[i+1]+=c[i]/10; c[i]%=10;`
- 最高位若还有进位，长度要加一
- C99 的 `for(int i=0;...)` 循环内声明

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
