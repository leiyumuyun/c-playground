# ex01_bubble_sort — 冒泡排序

## 作业内容

读入 n 和 n 个整数，两层循环相邻比较、逆序就交换，内层上界随已排好的元素递减；最后按空格分隔输出。

## 涉及知识点

- 冒泡排序 O(n²) 的双层循环结构
- 内层上界写 `n-1-i`，已排好的尾部不再比较
- 交换需要 `temp` 暂存
- 首个元素前不加空格的分隔技巧
- `main` 没有写 `return 0`（C99 起 `main` 会隐式返回 0）

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
