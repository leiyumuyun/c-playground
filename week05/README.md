# Week 05 — 数组

上课日期：2026-10-15

本周共 6 个作业，每个作业一个子目录，源码统一叫 `main.c`，编译运行方法见各子目录的 `README.md`。

## 作业列表

| 目录 | 作业 | 内容 |
|---|---|---|
| [ex01_bubble_sort/](ex01_bubble_sort/) | 冒泡排序 | 读入 n 和 n 个整数，两层循环相邻比较、逆序就交换，内层上界随已排好的元素递减；最后按空格分隔输出。 |
| [ex02_dedup_array/](ex02_dedup_array/) | 数组去重 | 把输入的数字依次和结果数组比较，只有没出现过才追加，保持首次出现的顺序，最后按空格输出。 |
| [ex03_longest_run/](ex03_longest_run/) | 最长连续相同段 | 扫一遍数组，相邻元素相同就把当前段长度加一，不同就更新最大值并重新计数；循环结束后还要再更新一次，否则最后一段会被漏掉。 |
| [ex04_primes_upto_n/](ex04_primes_upto_n/) | n 以内的素数 | 外层遍历 2 到 n，内层用 `j*j<=i` 试除，用 `flag` 标记是否被整除，没被整除的就是素数并输出。 |
| [ex05_polynomial_add/](ex05_polynomial_add/) | 多项式相加 | 输入若干「指数 系数」对，用 `-1` 表示一个多项式输入结束，两个多项式的系数累加到同一个数组里（下标即指数），再从高次到低次按 `3x^2+x-1` 的格式输出。 |
| [ex06_big_number_add/](ex06_big_number_add/) | 大数加法 | 读入两个长度不超过 500 位的十进制数，倒序逐位存进整型数组，数组逐位相加并处理进位，最后再倒序输出结果。 |

## 本周知识点

- 一维数组与变长数组 `int a[n]`
- 冒泡排序与变量交换
- 用计数器配合数组做去重
- 一次遍历统计连续段
- 用数组下标当指数/数位
- 以 `-1` 作为输入结束标记
- 大数用字符数组倒序存成整数数组做进位
