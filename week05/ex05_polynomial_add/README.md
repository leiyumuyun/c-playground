# ex05_polynomial_add — 多项式相加

## 作业内容

输入若干「指数 系数」对，用 `-1` 表示一个多项式输入结束，两个多项式的系数累加到同一个数组里（下标即指数），再从高次到低次按 `3x^2+x-1` 的格式输出。

## 涉及知识点

- 用数组下标当指数，`a[101]` 覆盖 0–100 次
- `while(1)` + `break` 处理不定长输入，`-1` 作结束标记
- 系数为 1 时省略、为 -1 时只打负号、为 0 时跳过
- 首项不加 `+` 号靠 `flag` 控制
- 从高次往下跳过前导 0，全 0 时输出 `0`

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
