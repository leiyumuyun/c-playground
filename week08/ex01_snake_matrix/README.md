# ex01_snake_matrix — 蛇形矩阵填充

## 作业内容

读入 n，用 n×n 二维数组按两条斜线方向交替（左下→右上、右上→左下）依次填入 1 到 n²，每走到边界就换向，最后按 `%4d` 对齐输出整个矩阵。

## 涉及知识点

- `scanf("%d", &n)` 读入矩阵阶数
- C99 变长数组 `int a[n][n]`
- `memset(a, 0, sizeof a)` 初始化二维数组
- 用 `turn` 区分两条斜线方向，用 `h` 控制当前斜线
- 边界判断与方向切换（到达第一行、最后一列、最后一行、第一列时换向）
- `printf("%4d")` 格式化输出矩阵
