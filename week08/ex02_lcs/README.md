# ex02_lcs — 最长公共子序列

## 作业内容

用 `fgets` 读入两行字符串并去掉行尾换行，建立二维动态规划表，逐格比较字符：相等时取左上角加一，否则取上方和左方的较大值，最后输出两个字符串的最长公共子序列长度。

## 涉及知识点

- `fgets` 读整行，`strcspn(a, "\n")` 去掉行尾换行
- `strlen` 取字符串长度，`memset` 清零二维表
- 二维数组 `int chart[200][200]` 作为 DP 表
- 动态规划状态转移：相等时 `chart[i][j] = chart[i-1][j-1] + 1`，否则 `max(chart[i-1][j], chart[i][j-1])`
- 自定义 `max` 函数与条件运算符 `a > b ? a : b`
- 下标从 1 开始、字符串下标用 `i-1` / `j-1` 的对应关系
