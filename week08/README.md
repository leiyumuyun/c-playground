# Week 08 — 二维数组与动态规划

上课日期：2026-10-29

本周共 2 个作业，每个作业一个子目录，源码统一叫 `main.c`，编译运行方法见各子目录的 `README.md`。

## 作业列表

| 目录 | 作业 | 内容 |
|---|---|---|
| [ex01_snake_matrix/](ex01_snake_matrix/) | 蛇形矩阵填充 | 读入 n，用二维数组按两条斜线方向交替填入 1 到 n²，每走到边界就换向，最后按 `%4d` 对齐输出。 |
| [ex02_lcs/](ex02_lcs/) | 最长公共子序列 | 用 `fgets` 读两行字符串，建立二维 DP 表，按字符相等/不等分别转移，输出最长公共子序列长度。 |

## 本周知识点

- C99 变长数组 `int a[n][n]` 与固定大小二维数组
- `memset` 初始化二维数组
- 方向状态机与边界换向（蛇形矩阵）
- `fgets` + `strcspn` 读整行并去换行
- 二维动态规划表的建立与状态转移（LCS）
- 自定义 `max` 函数与三元运算符
