# ex02_max_of_three — 三数最大值（自定义函数）

## 作业内容

定义 `max(a,b,c)` 用 `if` / `else if` 比较出三者最大值，`main` 读入三个整数后调用它并打印 `max=...`。注意读入格式串是 `%d,%d,%d`，输入时三个数之间要打逗号。

## 涉及知识点

- 自定义函数的定义与调用，参数按值传递
- `if` / `else if` / `else` 三个分支
- `scanf("%d,%d,%d")` 里的逗号是字面匹配，输入必须是 `1,2,3` 这种写法
- `printf("max=%d")` 输出带前缀的结果

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
