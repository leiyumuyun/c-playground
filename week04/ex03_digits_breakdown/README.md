# ex03_digits_breakdown — 数位分解

## 作业内容

读入一个整数，用 `while` 从低位开始把每一位存进数组，再从最高位往下、跳过多余的 0，按 `1*2*3*` 的格式打印每一位数字。

## 涉及知识点

- `int a[100]={0}` 把数组初始化为 0，靠 0 标记有效长度
- `while` 拆位，`n%10` 存入、`n/10` 收缩
- 从后往前找第一个非 0 元素，跳过前导 0
- 循环变量复用：拆位和打印各用一个 `i`
- 每个数字后面跟一个 `*`

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
