# ex08_bisection_root — 二分法求根

## 作业内容

对 `f(x)=x³-x²-1` 在区间 `[0,3]` 上二分：每次取中点看符号，把区间缩到含根的一半，直到区间长度小于 `1e-5`，输出中点。

## 涉及知识点

- 把 `f(x)` 抽成独立函数 `double f(double x)`
- 二分法的区间收缩逻辑
- 用 `f(low)*f(mid)<0` 判断根在哪一半
- 浮点不能用 `==` 判零，只能靠区间长度收敛
- `%.5f` 输出

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
