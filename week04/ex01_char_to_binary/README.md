# ex01_char_to_binary — 字符转 8 位二进制

## 作业内容

读入一个字符，从第 7 位到第 0 位逐位取出 `(c>>i)&1` 并打印，得到这个字符的 8 位二进制表示。

## 涉及知识点

- 位运算 `>>` 右移与 `&` 取位
- 从高位到低位遍历的递减 `for`
- `char` 是有符号的：输入负值字符（ASCII > 127）时右移会带符号扩展，高位是 1
- 不借助数组或字符串，逐位直接输出

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
