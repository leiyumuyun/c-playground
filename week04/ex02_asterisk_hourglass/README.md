# ex02_asterisk_hourglass — 星号沙漏图形

## 作业内容

读入 n，先打一行 `2n-1` 个带间隔的星号作为上边缘，再用 n-1 行画出向内收缩的轮廓，靠 `%*c` 按行算出的宽度做缩进。

## 涉及知识点

- `printf("%*c", w, ' ')`：用变量控制字段宽度
- 按行推导空格数：`2i` 与 `4n-4i-5`
- `2*n-1` 这类边界表达式直接写进循环条件
- 在 `if` 里用 `break` 提前结束循环

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
