# ex07_prime_factorization — 质因数分解

## 作业内容

读入 n，从 2 开始试除，能除尽就把因子收进数组并让 n 除掉它，除不尽才 `i++`；循环条件是 `i*i<=tmp`，最后若 n>1 它本身也是因子。输出形如 `n=2*3*5`。

## 涉及知识点

- 试除法：`i*i<=tmp` 就是 `i<=sqrt(tmp)` 的整数写法
- 数组收集因子，`int a[100]={0}`
- `while` 里两个并列 `if`：能除尽则收因子，除不尽才递增
- `if(n>1)` 处理最后剩下的素数因子
- `printf("%d=", n)` 先打前缀，之后用 `*` 拼接

gcc main.c -o main -Wall -Wextra
./main
