# ex02_narcissistic_numbers — 三位水仙花数

## 作业内容

遍历 100 到 999，把每个数拆出个位、十位、百位，若 `n == a³+b³+c³` 就输出，得到所有三位水仙花数。

## 涉及知识点

- 用临时变量 `temp` 连续两次取余取整拆出三位
- 立方写成连乘 `a*a*a`
- `for` 遍历区间，`if` 不带大括号只控制紧跟的一条语句
- 逐个输出，每行一个

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
