# ex04_hundred_chickens — 百钱百鸡

## 作业内容

公鸡 5 钱、母鸡 3 钱、小鸡 1 钱 3 只，100 钱买 100 只。双重 `for` 穷举公鸡和母鸡数，小鸡数由总数直接算出，判断 `z%3==0` 且 `5x+3y+z/3==100` 就输出一组解。

## 涉及知识点

- 二重循环穷举
- 用 `x+y+z=100` 把第三层循环化成一次减法
- 整数除法 `z/3` 与取余 `z%3` 配合判断整除
- 每找到一组解输出一行

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
