# ex03_triangle_classify — 三点坐标判定三角形类型

## 作业内容

读入三个点的坐标算出三条边长，先判断能否构成三角形；能则依次判断等边、等腰直角、等腰、直角、普通。浮点相等一律用 `fabs(...) < 0.00001`，不用 `==`。

## 涉及知识点

- `fabs` 做浮点容差比较，代替 `==`
- 用边长平方和判断直角：`s1²+s2² == s3²`（三个方向都试）
- 四个标志变量 `eq12` / `eq23` / `eq31` / `right` 组合出类型
- 分支顺序决定输出唯一：等边 → 等腰直角/等腰 → 直角 → 普通
- `math.h` + `-lm`

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra -lm
./main
```

本例调用了 `math.h` 的 `sqrt` / `fabs`，必须加 `-lm`，否则链接阶段会报 `undefined reference to sqrt`。
