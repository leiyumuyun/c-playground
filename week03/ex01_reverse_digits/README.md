# ex01_reverse_digits — 逆序输出各位数字

## 作业内容

读入一个整数，循环里每次取末位打印、再整除 10 把末位去掉，于是数字从低位到高位被打印出来，实现逆序。

## 涉及知识点

- `for` 循环的第三个表达式写成 `a=a/10`，用循环本身完成收缩
- `a%10` 取末位、`a/10` 去掉末位
- 循环条件 `a>=1` 判断是否还有位
- 不用数组、不用字符串，纯算术完成逆序

## 如何编译运行

```bash
gcc main.c -o main -Wall -Wextra
./main
```
